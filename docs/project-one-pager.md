# clinical-lab-qc

**一个可复现的 MoonBit 室内质控分析库**

检验实验室需要连续观察质控值。单个超限值并不能说明全部情况：试剂批号、控制品批号、校准和方案变化会改变哪些数据可以比较；复核人员也需要知道具体由哪些运行和观测触发了规则。

clinical-lab-qc 将质控数据建模为有序、可回放的轨迹。可复用的 MoonBit API 验证分析项目配置、检测六条 Westgard 风格规则、保存逐条证据，并在质控阶段变化时重置跨运行窗口。CLI 可读取长表 CSV，输出 Markdown、版本化 JSON、审计 CSV 和独立离线 Levey–Jennings SVG 图表。

仓库包含三种可运行的合成场景：

1. **稳定轨迹：**复核 12 次稳定运行，确认没有规则命中。
2. **批号/校准切换：**查看两个质控阶段，确认新阶段不继承旧阶段的规则窗口。
3. **渐进漂移：**检查 1_2s、4_1s、10x 信号及其对应观测证据。

设计重点是使用定精度缩放整数比较规则、把规则检测与复核策略分开、保持输入顺序，并且不插补缺失观测。报告保留运行和阶段上下文，方便重复计算和人工复核。

项目主要以 MoonBit 实现，采用 Apache-2.0 许可证，包含公开 API quickstart、多目标测试、CI 和一键验收检查：**python scripts/acceptance.py**。

仓库：https://github.com/impart563/clinical-lab-qc

**范围边界：**本项目是供合成或实验室质控数据使用的分析与复核辅助工具，不存储患者数据、不连接仪器或医院系统、不替代实验室 SOP、不作诊断，也不自动放行患者结果。演示数据和默认策略不是经验证的临床操作限值。
